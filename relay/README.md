# Ретранслятор AgentWatch

Нужен, чтобы офис на одном компьютере вёл агентов другого компьютера откуда угодно, без VPN.
Оба офиса подключаются сюда исходящим WebSocket. Сервер только пересылает кадры между двумя
участниками «комнаты»: содержимое зашифровано сквозным ключом между компьютерами
(X25519 + общий секрет → AES-256-GCM, свежие ключи на каждое соединение), ретранслятор его не читает
и не может подделать или повторить команду.

## Установка (Ubuntu 24.04, например AWS Lightsail nano)

1. Статический IP; открыть порты 80 и 443 (SSH — только со своего IP).
2. Скопировать папку `relay/` на сервер и запустить:
   ```
   sudo bash setup.sh 1-2-3-4.sslip.io      # домен вида <ip-через-дефисы>.sslip.io — TLS без своего DNS
   ```
3. В конце будет строка `wss://…/aw#ключ` — вставьте её в офисе: «Компьютеры» → «Ретранслятор».

Лимиты: ≤2 участника в комнате, ≤64 комнат, ≤8 соединений с IP, ~30 кадров/с и 4 МБ/с, кадр ≤4 МБ.
Тесты: `npm test`.
